## 🍌 소개

Seedream 5.5는 정밀한 부분 수정, 일관된 다중 편집, 자연스러운 피사체와 조명, 읽기 쉬운 텍스트, 투명 소재, 재사용 가능한 레이어 등 이미지 제작 워크플로에 중점을 둡니다. 가이드를 읽고 5.5 사례를 확인한 뒤, 이전 5.0 Pro 사례 모음을 살펴보세요.

Seedream 5.5 사례 9개 · Seedream 5.0 Pro 제품 사례 25개 · Seedream 5.0 Pro 커뮤니티 사례 39개. 기존 예시는 원래 모델 버전과 출처 링크를 유지합니다.

## 📘 Seedream 5.5 가이드

### 평가할 항목

- 정밀한 반복 편집: 이미지의 나머지 부분을 유지하면서 지정한 영역이나 요소를 변경합니다. 제공된 시계 시연은 100회 연속 편집을 보여 줍니다.
- 사실감: 참조 이미지를 조합할 때 표정, 신체 비율, 소재 질감, 물체 크기, 원근, 조명을 확인합니다.
- 작은 글씨와 다국어 텍스트: 포스터, 라벨, 인포그래픽의 정확한 문구, 텍스트 위계, 줄바꿈, 위치를 지정합니다.
- 투명 소재: 투명 배경과 투명한 재질을 구분하고, 비어 있는 영역과 반투명·불투명 영역을 지정합니다.
- 레이어 워크플로: 제품 자료는 배경, 요소, 텍스트를 분리하여 후속 편집과 다른 언어 버전 제작에 활용하는 방식을 설명합니다. 레이어 출력은 병합된 미리보기와 별도로 확인하세요.

### 프롬프트 작성 방법

결과물, 피사체, 공간 배치, 소재, 조명을 정의하세요. 편집할 때는 변경할 내용과 유지할 세부 사항을 명확하게 지정합니다. 각 회차의 지시는 실제 입력 이미지를 기준으로 하며, 그 자체로 이해할 수 있어야 합니다.

| 작업 | 지정할 정보 |
|---|---|
| 그래픽 디자인 생성 | 결과물 형식을 명시하고 제목, 메인 비주얼, 정보, 브랜드 영역을 배치합니다. 모든 문구를 정확히 쓰고 위계를 정의합니다. |
| 그래픽 디자인 편집 | 각 참조 이미지의 역할을 정하고, 유지·변경·이동·삭제할 항목을 지정합니다. 최종 배치와 정확한 대체 문구를 설명합니다. |
| 상품 소개 이미지 제작 | 상품 형태, 색상, 소재, 로고를 고정합니다. 평면 배치, 걸기, 착용, 콜라주 중 방식을 정하고 시점, 크롭, 모델, 조명을 지정합니다. |
| 투명 소재 생성 | 배경 투명도를 유리나 반투명 재질과 별도로 지정합니다. 오려 낸 영역, 윤곽, 채움, 피사체의 보이는 부분을 설명합니다. |
| 인포그래픽 또는 슬라이드 생성 | 배경과 전체 배치를 먼저 설명한 뒤, 모듈 위치, 정확한 문구와 데이터, 차트 유형, 축, 추세, 범례, 주석을 지정합니다. |
| 인포그래픽 또는 슬라이드 편집 | 원본 요소와 최종 역할의 관계를 정합니다. 추가·교체 항목, 화살표 양 끝점, 정렬, 겹침, 일관된 글꼴을 지정합니다. |
| 스토리보드 생성 | 칸 수와 읽는 순서를 정하고 이야기 흐름, 샷 크기, 각도, 렌즈와 심도 표현, 조명, 인물, 연속성을 설명합니다. |
| 참조 이미지로 스토리보드 제작 | 참조가 인물, 분위기, 배경, 첫 프레임, 마지막 프레임 중 무엇을 제공하는지 밝히고 동작과 카메라의 연속성을 설명합니다. |
| 이야기 이미지 이어 만들기 | 시간적 연결 관계를 명시하고, 카메라 움직임, 피사체의 다음 행동, 화면에 들어오거나 나가는 요소를 설명합니다. |
| 카메라 표현 조정 | 샷 크기, 카메라 시점, 초점 변화를 구분합니다. 시작점, 방향, 끝점, 유지할 장면의 세부 사항을 지정합니다. |
| 부분 보정 | 정확한 영역, 작업, 강도를 지정합니다. 결과의 질감과 경계를 설명하고, 인물의 정체성과 수정하지 않는 영역을 유지합니다. |
| 전체 편집 또는 여러 참조 합성 | 스타일을 색상, 대비, 입자감, 빛으로 구체화합니다. 구도와 자세를 정하고 참조 이미지의 역할과 유지할 인물 특징을 지정합니다. |
| 스케치를 이미지로 변환 | 위치와 색상으로 표시를 구분하여 물체에 대응시킵니다. 의도한 크기와 배치를 유지하고 포스터 문구는 별도로 제공합니다. |
| 정확한 텍스트 생성 | 텍스트를 담을 매체를 정하고 모든 문자를 인용합니다. 읽는 순서, 줄 수, 정렬, 간격, 삽화와의 관계를 정의합니다. |
| 이미지 속 텍스트 교체 | 기존 문구와 정확한 새 문구를 대응시킵니다. 철자, 배치, 수정하지 않는 영역을 유지하고 드러나는 배경을 자연스럽게 복원합니다. |
| 여러 회차에 걸쳐 편집 | 현재 출력을 다음 입력으로 사용합니다. 대상의 현재 상태와 목표 변화를 명시하고, 중요한 유지 조건을 반복합니다. |

비교 조건: 아래 예시는 제공된 시연 자료이며, 이 저장소에서 재현한 벤치마크가 아닙니다. 역광 비교 모델은 자료에 이름이 공개되어 있지 않습니다. 시계 비교에는 Image 2.5, Sunburst/xhigh가 명시되어 있습니다. 프롬프트 첨부 파일에는 1~60회차가 수록되어 있고, 영상은 100회 연속 편집으로 제시되어 있습니다.

제품 예시는 부분 편집, 인물, 조명, 포스터 텍스트, 텍스트 소재 표현, 투명 소재 조합을 다룹니다. 정확한 프롬프트 원문은 자료에서 제공된 경우에만 수록합니다. 가이드에서 설명하는 RGBA와 레이어 기능은 시각적 미리보기뿐 아니라 내보낸 파일을 통해 평가해야 합니다.
